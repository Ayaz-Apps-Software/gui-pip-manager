# GUI Pip Manager

A graphical interface for Python package management, built with CustomTkinter.  
This project is distributed under the Ayaz License.

## Features
- Install / Uninstall Python packages
- List all installed packages
- Thread-safe command execution
- Dark mode user interface

## Download
You can download the compiled executable from the [Releases](https://github.com/Ayaz-Apps-Software/gui-pip-manager/releases) section.

## Installation
Clone the repository and run:
git clone https://github.com/Ayaz-Apps-Software/gui-pip-manager.git
cd gui-pip-manager
python main.py
